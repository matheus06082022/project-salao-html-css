Project-Salão

📌 Descrição
Projeto web desenvolvido de forma individual com o objetivo de praticar desenvolvimento front-end,
estruturação de páginas e estilização utilizando HTML e CSS.

O projeto consiste em um **site para divulgação de serviços de salão**, criado para demonstrar
o trabalho realizado e atrair novos clientes por meio de uma presença online simples e funcional.

🛠️ Tecnologias utilizadas
- HTML
- CSS
- Git e GitHub

🎨 Funcionalidades
- Página institucional para apresentação do salão
- Seção de serviços oferecidos
- Informações de contato
- Layout responsivo
- Estilização personalizada com CSS
- botão de WhatsApp
- links de redes sociais
